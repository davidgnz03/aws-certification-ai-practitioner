# 📜 AWS Artifact  
## Compliance & Audit Documentation Portal

---

### 🧱 Overview

**AWS Artifact** no es un servicio técnico, sino un **portal de autoservicio** que brinda acceso bajo demanda a la **documentación de cumplimiento y seguridad de AWS**, así como a los **acuerdos legales** necesarios para operar en entornos regulados.

> 🏛️ *Piensa en AWS Artifact como tu “biblioteca de cumplimiento” en la nube.*

---

## 📚 Core Capabilities

| **Funcionalidad** | **Descripción** |
|--------------------|-----------------|
| **Artifact Reports** | Descarga documentos de cumplimiento y seguridad de AWS verificados por auditores externos. |
| **Artifact Agreements** | Administra acuerdos legales con AWS relacionados con el cumplimiento normativo. |
| **Third-Party Reports** | Acceso a reportes de cumplimiento de proveedores externos (ISVs) mediante AWS Marketplace Vendor Insights. |
| **Audit Support** | Facilita auditorías internas o externas al proporcionar documentación oficial y verificable. |

---

## 🧾 AWS Artifact Reports

**AWS Artifact Reports** te permite descargar de forma inmediata:

- **Certificaciones y auditorías de seguridad de AWS**, incluyendo:
  - ✅ **ISO 27001, 27017, 27018**
  - 💳 **Payment Card Industry Data Security Standard (PCI DSS)**
  - 🧮 **System and Organization Controls (SOC 1, SOC 2, SOC 3)**  
- Reportes de terceros auditores independientes sobre:
  - Controles de seguridad.
  - Privacidad y gestión de datos.
  - Cumplimiento regulatorio global.

> 📥 *Ideal para departamentos de cumplimiento, seguridad y auditoría interna.*

---

## 🧾 AWS Artifact Agreements

**Artifact Agreements** permite revisar, aceptar y administrar acuerdos legales con AWS que respaldan el cumplimiento de tu organización.

### 🧩 Ejemplos de acuerdos disponibles:

| **Acuerdo** | **Propósito** |
|--------------|---------------|
| **Business Associate Addendum (BAA)** | Requisito para manejar datos protegidos bajo la ley **HIPAA** (sector salud). |
| **HIPAA Agreement** | Formaliza la relación de cumplimiento con AWS para servicios que manejan PHI (*Protected Health Information*). |
| **Individual or Organizational Level** | Puedes aceptar acuerdos para una **cuenta individual** o **toda una organización (Organizations)**. |

> ⚖️ *Permite demostrar cumplimiento legal y técnico ante auditores o clientes.*

---

## 🧩 Third-Party Reports (ISVs)

AWS Artifact también proporciona acceso a **informes de cumplimiento de proveedores externos (ISVs)** integrados con **AWS Marketplace Vendor Insights**.

### 🔍 Características principales:

- Acceso bajo demanda a **reportes de seguridad y cumplimiento** de **Independent Software Vendors (ISVs)**.  
- Solo los **clientes aprobados** para un proveedor específico pueden acceder a sus reportes.  
- Capacidad de **recibir notificaciones** automáticas cuando se publican nuevos informes o certificaciones.

> 🧠 *Esto facilita la evaluación de seguridad antes de integrar soluciones de terceros en tu arquitectura.*

## 🧠 Use Cases

| **Caso de Uso** | **Descripción** |
|------------------|-----------------|
| **Auditorías Internas** | Proporciona evidencia verificable sobre el cumplimiento de AWS en estándares internacionales. |
| **Regulatory Compliance** | Acelera la preparación para auditorías ISO, SOC, PCI, HIPAA, etc. |
| **Third-Party Risk Management** | Evalúa el cumplimiento de seguridad de los proveedores en AWS Marketplace. |
| **Contractual Alignment** | Formaliza acuerdos regulatorios (como HIPAA o GDPR) con AWS. |

---

## ⚙️ How It Works

1. **Accede a la consola de AWS Artifact**.  
2. **Selecciona la pestaña "Reports" o "Agreements"** según lo que necesites.  
3. **Descarga documentos** o **acepta acuerdos** directamente desde la interfaz.  
4. **Recibe notificaciones automáticas** cuando nuevos informes estén disponibles.  
5. **Utiliza los reportes** para respaldar tus auditorías o revisiones de cumplimiento.

> 🧩 *No requiere configuración técnica: todo se gestiona desde la consola de AWS.*

---

## 💰 Pricing Overview

- **AWS Artifact es completamente gratuito.**  
- No se cobran tarifas por descargar documentos o aceptar acuerdos.
- Algunos acuerdos (como HIPAA o BAA) pueden requerir revisión legal interna.

> 💡 *El costo está en el tiempo de auditoría, no en el uso del servicio.*
