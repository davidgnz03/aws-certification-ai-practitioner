# 🧮 AWS Audit Manager  
## Continuous Auditing & Compliance Automation

---

### 🧱 Overview

**AWS Audit Manager** es un servicio administrado que te permite **auditar de forma continua** el uso de tus servicios en AWS, facilitando la **evaluación de riesgos** y el **cumplimiento normativo**.

> 🧾 *Audit Manager automatiza la recolección de evidencia y genera reportes listos para auditorías.*

---

## ⚙️ Core Capabilities

| **Funcionalidad** | **Descripción** |
|--------------------|-----------------|
| **Continuous Audit** | Supervisa el entorno AWS de forma continua para recopilar evidencia y verificar cumplimiento. |
| **Automated Evidence Collection** | Recopila automáticamente logs, configuraciones y métricas relevantes para auditorías. |
| **Prebuilt Frameworks** | Plantillas listas para cumplir con estándares como **ISO 27001**, **HIPAA**, **PCI DSS**, **SOC 2**, entre otros. |
| **Custom Frameworks** | Crea tus propios marcos de cumplimiento personalizados según tus políticas internas. |
| **Risk Assessment** | Evalúa el nivel de cumplimiento y los riesgos asociados a cada control. |
| **Audit Reports** | Genera reportes listos para presentación ante auditores o revisores de cumplimiento. |

> ⚙️ *Reduce el trabajo manual en las auditorías mediante recopilación automática y continua de evidencia.*

---

## 🧩 How It Works

1. **Selecciona un Framework**  
   Escoge entre plantillas predefinidas (por ejemplo, HIPAA, SOC 2, GDPR) o crea una personalizada.

2. **Mapeo Automático de Controles**  
   Audit Manager identifica los **controles** asociados y los vincula con los **servicios AWS** relevantes.

3. **Recopilación Continua de Evidencia**  
   El servicio recopila configuraciones, eventos, logs y métricas desde servicios como:
   - **AWS Config**
   - **AWS CloudTrail**
   - **AWS Security Hub**
   - **Amazon S3**
   - **AWS IAM**

4. **Evaluación y Revisión**  
   Los resultados se presentan en un panel con el **estado de cumplimiento**, **niveles de riesgo**, y **acciones recomendadas**.

5. **Generación de Reportes**  
   Puedes exportar reportes en formatos compatibles con auditores internos o externos.

> 🧠 *El servicio automatiza el ciclo completo de auditoría: desde la recolección hasta la evidencia final.*

| **Framework** | **Descripción** |
|----------------|-----------------|

| **PCI DSS** | Requisitos de seguridad para datos de tarjetas de pago. |

| **CIS AWS Foundations** | Buenas prácticas de seguridad para configuraciones AWS. |

> 📚 *También puedes importar tus propios frameworks personalizados.*

## 🧩 Integrations

AWS Audit Manager se integra con varios servicios clave:

| **Servicio Integrado** | **Función** |
|--------------------------|-------------|
| **AWS Config** | Monitorea configuraciones de recursos y desviaciones. |

> 🧩 *Estas integraciones permiten auditar de manera holística toda la infraestructura AWS.*
